# NOVALI v7 Public Handoff Package

This package is a sanitized guided handoff for local evaluation and development.

Start here:

1. Read `README_FIRST.md`.
2. From the repository root, run `launch/00_first_run_wizard.ps1`.
3. Open `http://127.0.0.1:8787/shell`.
4. Load or generate a generic directive.

Private live directives, active workspaces, runtime ledgers, spill-volume state, secrets, and telemetry captures are intentionally excluded.
