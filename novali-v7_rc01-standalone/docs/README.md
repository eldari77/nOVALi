# NOVALI v7 Standalone Documentation

This folder is intentionally small in the public handoff. The first-run path is:

1. Read `README_FIRST.md` in the package root.
2. Run the repository-level wizard at `launch/00_first_run_wizard.ps1`.
3. Open `http://127.0.0.1:8787/shell`.
4. Generate or load a directive from a generic template in `samples/directives/`.
5. Use the Operator Shell to bootstrap, continue governed work, and engage autonomy.

Live runtime ledgers, active workspaces, pending LLM directives, spill-volume contents, and private telemetry state are excluded from this package.
