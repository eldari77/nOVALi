# Public Package Contents

## Included

- NOVALI v7 standalone source and Operator Shell.
- Docker and launch helpers for the guided handoff.
- Generic directive samples.
- Trusted-source pack seeds that are safe to publish.
- Placeholder runtime directories with README files.

## Excluded

- Private directives and pending LLM directive drafts.
- Active workspace artifacts.
- Runtime JSONL ledgers and checkpoint state.
- Spill-volume state and Librarian runtime packs.
- Secrets, private provider credentials, and local telemetry captures.
