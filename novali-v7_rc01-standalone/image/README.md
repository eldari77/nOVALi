# Image Archive

This directory contains the runnable Docker image archive for the guided public handoff.

- Archive: `novali-v7-standalone.tar`
- Image tag after loading: `novali-v7-standalone:local`
- Checksum manifest: `image_archive_manifest.json`

Load it with `standalone_docker/load_image_archive.ps1` or run the repository-level first-run wizard.
