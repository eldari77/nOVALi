# Localhost Web Operator UI

The standalone package serves the React Operator Shell at:

```text
http://127.0.0.1:8787/shell
```

The first viewport should answer:

- Is NOVALI safe?
- What is it doing?
- What needs operator attention?
- What is the next bounded action?

The shell includes Overview, Attention Queue, Directive Work, Autonomy + Runtime, and Librarian tabs. Emergency stop remains visible as an operator safety control.
