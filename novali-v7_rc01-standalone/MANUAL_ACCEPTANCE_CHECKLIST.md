# Manual Acceptance Checklist

- Docker image archive loads successfully.
- `/shell` opens from `http://127.0.0.1:8787/shell`.
- A generic directive can be generated or loaded.
- Bootstrap reports a reviewable state.
- Governed continuation starts only through the shell controls.
- Pause and emergency stop are visible.
- No private directives, active workspace artifacts, runtime ledgers, secrets, or telemetry captures are present.
